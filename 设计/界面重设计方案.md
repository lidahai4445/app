# 纸间 · 平板版界面重设计方案（草案 v1）

> 2026-09-28 · 配套效果图：`界面效果图.html`（浏览器打开，顶部可切换 4 个界面）
> 目标：**简洁，但不简陋**。纸张是主角，界面退后，但每一处都有层次、有反馈、有细节。

---

## 1. 现在为什么显得“简陋”

| 问题 | 现状（Android 2.0） | 结果 |
|---|---|---|
| 没有层次 | 顶部 52dp 一行塞了 返回 / 标题 / 做题辅助 / 计时 / 设置 | 视线无处落脚，像调试界面 |
| 默认组件直接堆 | M3 默认按钮、分段按钮、FAB、AlertDialog 原样使用 | “能用”，但没有产品个性 |
| 信息太少 | 资料库只有封面 + 一行页码；空状态一句话 | 打开 App 不知道“接下来做什么” |
| 工具栏是通栏 | 做题工具贴在屏幕底部整行 | 占地方、离笔远、不像纸上工具 |
| 视觉语言不统一 | 蓝灰配色，与网页版的松石绿、纸感不一致 | 两个版本像两个产品 |
| 缺反馈与动效 | 加载只有转圈；切换无过渡 | 显得粗糙、不可靠 |

## 2. 设计原则

1. **纸张优先**：页面居中、真实纸感阴影；做题时所有工具都“浮”在纸上方，可自动淡出。
2. **一处只做一件事**：顶栏只负责“我在哪 + 模式切换”；工具胶囊只负责“怎么写”；侧栏只负责“辅助内容”。
3. **克制的颜色**：一个主色（松石绿，代表“做题/自己”）+ 一个 AI 色（琥珀，代表“辅助/AI”），其余全部是墨色和纸色的灰阶。用户一眼能分清“哪些是我写的，哪些是 AI 给的”。
4. **有反馈**：每个异步操作都有状态：骨架屏、“来自本地缓存”标记、保存状态、识别进度。
5. **手写体验优先于一切**：笔写字，手指滑动/缩放，手掌不误触。

## 3. 设计令牌（统一全 App，网页版可共用）

| 类别 | 取值 |
|---|---|
| 纸色背景 | `#F5F3ED`；卡片 `#FFFFFF`；次级面 `#FAF9F5` |
| 墨色文字 | 主 `#1D2926` · 次 `#4A5752` · 弱 `#86928D` |
| 主色（做题） | `#2F6B52`，浅底 `#E7F0EA` |
| AI 色（辅助） | `#B8733A`，浅底 `#FBF1E6` |
| 线条 | `#E5E7E0` |
| 圆角 | 8 / 12 / 18 / 26 dp（小控件 / 按钮 / 卡片 / 弹层） |
| 阴影 | 3 级：贴面 · 悬浮（工具胶囊、卡片）· 弹出（弹窗、纸张） |
| 字号 | 25 标题 / 18 卡片标题 / 14 正文 / 12.5 说明 / 11 标签；数字用等宽数字 |
| 间距 | 4 的倍数：4 / 8 / 12 / 16 / 24 / 32 |
| 动效 | 150–250 ms，标准缓动；面板滑入、胶囊淡入淡出、卡片展开 |
| 图标 | 统一 Lucide 线性图标，1.8 描边（与网页版一致） |
| 暗色 | 同一套令牌的暗色版（纸色→`#1B1C1E`，纸张本身可选“护眼暖灰”） |

## 4. 各界面设计

### ① 资料库
- **左侧导航**：全部试卷 / 最近打开 / 收藏 / 生词本 + 科目（英语一、数学一、政治，带色标，可自定义）+ 设置。
- **顶部问候 + 本周统计**（专注时长、完成套数），给打开 App 一点“仪式感”。
- **“继续上次”大卡片**：封面、当前位置（阅读 Text 2 · 第 3/12 页）、进度条、已用时、查词数，一个按钮直接回到上次的页。
- **封面网格**：拟纸张叠层阴影 + 科目色条 + 进度细条 + “已完成”角标；长按出菜单（重命名、改科目、收藏、删除）。
- 搜索同时搜试卷名和生词；排序：最近打开 / 名称 / 导入时间。
- 空状态：插画 + “导入第一份真题” + 支持“用纸间打开”说明。

### ② 做题模式
- **顶栏**：返回 · 试卷名 + 当前位置 · 居中“做题 | 辅助”切换 · 右侧 计时胶囊（只显示“计时中·已隐藏”，**不显示数字**）、搜索、侧栏、更多。
- **悬浮工具胶囊**（纸张上方居中）：笔 / 荧光笔 / 橡皮 / 套索 / 文字 ｜ 4 个常用色 ｜ 3 档粗细 ｜ 撤销 重做。长按颜色可自定义。书写时胶囊自动变淡，抬笔后恢复。
- **左侧页面缩略图栏**（可收起）：当前页高亮，有笔迹的页带小圆点。
- 底部页码胶囊；翻页支持左右滑、缩略图点击、键盘/翻页笔。
- 手势：笔 = 书写；单指 = 滑动；双指 = 缩放/平移；双指轻点 = 撤销，三指轻点 = 重做（GoodNotes 习惯）。

### ③ 辅助模式
- 工具胶囊换成：**点词 / 划句 / 圈题解答** + 本页识别状态（“本页已识别 · 612 词”）。
- **点词 → 就地弹出小卡片**（不用跑去侧栏看）：单词、音标、发音、词性释义、**语境义**；按钮：加入生词本、固定到侧栏；命中缓存时显示“来自本地缓存”。
- **圈题 → 出现琥珀色“AI 解答此题”按钮**，确认后才发请求（避免误触浪费额度）。
- **右侧面板**三个标签：本页（本页所有辅助卡片）/ 生词 / 解题。AI 解题卡片分步骤展示，末尾对照“答案 vs 你的选择”；加载中显示骨架屏，不是转圈。
- 做题模式下，辅助内容全部隐藏，只保留你自己的笔迹。

### ④ 结束计时
- 点计时胶囊 → 确认结束 → 才第一次看到用时，同时给出：题目作答数、查词数、AI 解题数，建议用时对比。
- 两个按钮：“返回继续看” / “切换到辅助模式对答案”。
- 每次练习记录保存，资料库统计由此而来。

## 5. 技术方案（成熟优先）

### 如果是 Android 平板（沿用现有 Kotlin + Compose + M3）
- **自适应布局**：`WindowSizeClass` + Material3 Adaptive（导航栏/侧栏按宽度自动切换，手机竖屏自动退化为底部导航 + 底部面板）。
- **主题**：把第 3 节令牌写成 `PaperlyTheme`（颜色、字体、形状、阴影），组件全部从这里取值，不再直接用默认色。
- **自绘关键组件**：工具胶囊、封面卡片、辅助弹卡、AI 解题卡、计时胶囊、骨架屏。其余（对话框、菜单、输入框）用 M3 并统一换肤。
- **手写**：区分 `TOOL_TYPE_STYLUS`/手指；压感粗细；低延迟书写可评估 Jetpack 的 **androidx.ink**（官方墨迹库）或 `androidx.graphics` 前缓冲渲染。**具体版本与稳定性需实施前核实。**
- **PDF**：系统 `PdfRenderer`，放大时分块重绘保证清晰。
- 数据层（SQLite、翻译缓存、AI 接口）**不动**，只重做界面层，风险可控。

### 如果是 iPad
- Android 包在 iPad 上不能运行。iPad 原生最成熟的是 **SwiftUI + PencilKit（苹果官方手写，自带压感、防误触、套索）+ PDFKit**，手写体验最好，但**必须有 Mac + Xcode** 才能编译安装。
- 没有 Mac 的替代：把网页版改成 iPad 可安装的 **PWA**（添加到主屏幕、全屏、Apple Pencil 可用），界面按本方案重做即可。

## 6. 实施步骤（确认后执行，每步都记日志、先备份）

1. 主题与设计令牌（`PaperlyTheme`、图标、字体、形状）。
2. 资料库重做（导航、继续卡片、封面网格、空状态、长按菜单）。
3. 阅读器外框（顶栏、计时胶囊、缩略图栏、页码胶囊）。
4. 做题工具胶囊 + 手势（笔/手指区分、双指撤销）。
5. 辅助模式（就地弹卡、圈题按钮、三标签侧栏、骨架屏）。
6. 结束计时统计页 + 练习记录。
7. 暗色模式、动效、细节打磨；在真机上逐屏截图验收。
