# 纸间 Paperly

面向考研真题 PDF 的原生 Android 做题 / 辅助阅读 App，平板优先，同时适配手机。

- 技术栈：Kotlin · Jetpack Compose · Material 3 · SQLite · PdfRenderer · ML Kit
- 包名：`com.paperly.mobile`
- 当前版本：**2.3.0**（versionCode 7），minSdk 26 / targetSdk 36

## 功能

**资料库**
- 通过文件选择器导入 PDF，复制到应用私有目录，不修改原文件
- 分类、收藏、重命名、最近打开、继续阅读
- 平板：左侧导航 + 继续阅读主卡片 + 本周专注统计 + 试卷封面网格；手机：紧凑纵向布局

**做题模式**
- 逐页显示 PDF，笔 / 荧光笔、橡皮擦、撤销 / 重做
- 笔迹按页本地保存，支持双指缩放与平移
- 计时进行中隐藏用时，结束后显示统计与复盘入口

**辅助模式**
- ML Kit 离线 OCR（英文，可选中文），点词 / 划句翻译
- **框选截图解题（2.3.0）**：框选题目区域 → 虚线框确认 → 截图发送给视觉模型识图解题，不再依赖 OCR，排版混乱的文档也能识别；出结果后框自动消失
- 翻译支持自定义兼容接口，也提供联网的免费翻译回退；OCR 与解答结果本地缓存

**学习回顾**
- 近七天专注时长与练习数、累计查词、最近计时记录，全部来自真实数据

**设置**
- API Key 由 Android Keystore 加密保存；平板双栏显示
- 解题模型需支持图片；留空时按服务自动选择视觉模型。DeepSeek 等无视觉模型的服务需手动填写视觉模型，或改用智谱 `glm-4.6v-flash`（免费）

> 笔迹和译文是 App 的本地叠加层，不写入原 PDF；暂不支持导出带批注的 PDF。AI 服务只在翻译或确认框选时收到所选文本 / 截图。

## 构建

需要 JDK 17 与 Android SDK（build-tools 36）。

```bat
set "JAVA_HOME=%LOCALAPPDATA%\Programs\PaperlyToolchain\jdk17.0.20_12"
set "PATH=%JAVA_HOME%\bin;%PATH%"
gradlew.bat :app:assembleDebug
```

输出：`app/build/outputs/apk/debug/app-debug.apk`

## 安装与升级

- 使用同签名 APK **原位升级**（`adb install -r`），**不要卸载或清除数据**，否则本地资料和笔迹会丢失
- 数据库通过 v1→v2 迁移保留旧资料
- APK 不随源码提交，请从 Releases 获取
